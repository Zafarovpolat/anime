# Panelia — Manga Online Platform

Веб-приложение для чтения манги, манхвы и маньхуа онлайн. Разработано на Next.js 14 с использованием App Router и TypeScript. Интерфейс полностью реализован по дизайну из Figma.

## О проекте

**Panelia** — онлайн-платформа для чтения манги, аналог Mangalib/Readmanga. Проект включает:

- Главную страницу с подборкой манги, закладками и последними обновлениями
- Каталог с фильтрацией по жанру, году, рейтингу и количеству глав
- Страницу манги с описанием, главами, рейтингом, отзывами и комментариями (с редактированием, ответами и rich-text)
- Встроенный ридер глав с панелью комментариев
- Страницу профиля пользователя (закладки, история чтения, отзывы, комментарии, настройки)
- Модальное окно авторизации с OAuth (Telegram, Яндекс, VK, Google)
- Админ-панель: произведения, главы, пользователи, комментарии

На данный момент — **полноценный UI-прототип** с моковыми данными, готовый к подключению бэкенда. Актуальный статус разработки и план оставшихся задач — см. [`PLAN.md`](./PLAN.md).

### Каталог — фильтры

Страница `/catalog` содержит 14+ хуков состояния и реализует:

- Поиск по названию
- Фильтрация по жанрам (мультиселект с поиском)
- Диапазон года выпуска
- Диапазон рейтинга
- Диапазон количества глав
- Несколько вариантов сортировки
- Пагинацию с умными эллипсами (`1, 2, 3 … 47, 48`)

## Компоненты

### `Header.tsx`

Навигационная панель с логотипом, поиском, переключателем темы и кнопкой входа. Управляет открытием `LoginModal`.

### `MangaGrid.tsx`

Сетка карточек манги. На мобильных устройствах отображает 2 карточки, на десктопе — все. Определяет размер экрана через `MediaQueryList`.

### `BookmarksCarousel.tsx`

Карусель на базе Swiper с 10 закладками и навигационными кнопками. Адаптируется под 6 брейкпоинтов.

| Ширина экрана | Слайдов видно |
|---------------|---------------|
| 0px           | 1.3           |
| 400px         | 1.8           |
| 540px         | 2.3           |
| 768px         | 3             |
| 1024px        | 4             |
| 1280px        | 5             |

### `UpdatesSection.tsx`

Список последних обновлений глав. Содержит:
- Переключатель «Только мои закладки»
- Кнопку «Показать ещё»

### `Footer.tsx`

Подвал с копирайтом, ссылками на юридические страницы, иконками VK/Telegram и брендингом «Made by».

### `LoginModal.tsx`

Модальное окно авторизации:
- Поля email и пароль
- OAuth-кнопки: Telegram, Яндекс, VK, Google
- Ссылка на регистрацию
- Закрытие по клику на оверлей или клавише Escape

### `SearchDropdown.tsx`

Выпадающий поиск в шапке: ищет одновременно по произведениям и пользователям (моковые данные), показывает карточки с обложкой/аватаром.

### `CustomSelect.tsx`

Кастомный выпадающий select, используется в фильтрах каталога и формах админ-панели.

### `BookmarkModal.tsx`

Выбор или создание закладки с выбором цвета (вместо исходных эмодзи-иконок закладки теперь отображаются цветными кружками).

### `ReviewModal.tsx`

Модальное окно оценки произведения (10-балльная шкала со звёздами) отдельно от написания отзыва.

### `ReportModal.tsx`

Модальное окно жалобы на комментарий/отзывы с выбором причины.

### `RichTextEditor.tsx`

Кастомный рич-текст редактор для комментариев (используется на странице манги и в ридере): жирность, курсив, зачёркивание, цитата, спойлер (скрытие/раскрытие по клику), эмодзи-пикер. Поддерживает создание, редактирование и ответы на комментарии (сейчас через подстановку ника в плоский список, без вложенности/веток).

### `AdminLayout.tsx`

Общий сайдбар для страниц `/admin/*` с навигацией (Произведения / Пользователи / Комментарии) и ссылкой возврата на сайт.

## Структура данных

Бэкенд ещё не подключён. Данные моковые, описаны TypeScript-интерфейсами прямо в компонентах:

```typescript
// Карточка манги
interface MangaCard {
  id: number;
  coverIdx: number;      // 1–12, маппится на cover_X.jpg
  title: string;
  rating?: number;
  genres?: string[];
}

// Глава
interface Chapter {
  volume: number;
  chapter: number;
  date: string;          // "DD.MM.YYYY"
  views: string;
  likes?: string;
}

// Комментарий
interface Comment {
  id: number;
  avatar: string;
  username: string;
  text: string;
  time: string;
  likes: number;
  dislikes: number;
}

// Детали манги
interface MangaDetail {
  title: string;
  genres: string[];
  likes: string;
  views: string;
  bookmarks: string;
  rating: number;
  ratingCount: string;
  description: string[];
  totalChapters: number;
  totalReviews: number;
}
```

## Адаптивность

Проект следует принципу **mobile-first**. Ключевые брейкпоинты:

- **320–539px** — мобильные
- **540–767px** — планшеты (портрет)
- **768–1023px** — планшеты (ландшафт)
- **1024–1279px** — ноутбуки
- **1280px+** — десктоп

Каталог на мобильных открывает фильтры как drawer-оверлей. На десктопе — боковая панель.
